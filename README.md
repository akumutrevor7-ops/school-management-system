# School Management System

A modern school administration dashboard built with Next.js, TypeScript, and Tailwind CSS.

## Features

- Dashboard overview with key school metrics
- Student records management
- Teacher directory
- Attendance monitoring by class
- Fee tracking
- Exam result viewing
- Local persistence using browser localStorage

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Project structure

- `app/page.tsx` - app entry point
- `components/school-dashboard.tsx` - dashboard UI and logic
- `app/globals.css` - Tailwind styles

## Notes

This project is designed as a polished front-end prototype for a school management system. It includes realistic sample data and interactive UI for admin use.
